## 一、项目概述

**Lumen**（原「数据地图」，主人觉得旧名不好听，于 2026-08-09 更名）是面向内部使用的数仓表元数据展示系统，数据源为 Supabase 的 `dw_tables` 表。

- 名称寓意：Lumen（流明，光之单位）——呼应标语 *Illuminate what's stored*，照亮数仓中沉睡的元数据
- 核心能力：数仓表元数据总览（项目 / 层级 / 数据域 / 任务类型 的检索与统计）
- 使用对象：仅授权人员（不开放注册）
- 后端：Supabase（Auth + Postgres + RLS）

## 四、账号与权限体系（重要决策）

### 4.1 不开放注册
项目包含敏感数仓元数据，**不允许自助注册**。登录页无注册入口；Supabase 侧也建议关闭 signup（见 §六 待办）。

### 4.2 管理员账号
| 项 | 值 |
|----|-----|
| 用户名 | Yuanwdii |
| 邮箱 | yuanwdii@gmail.com |
| 权限 | 读 + 写 |

- 账号已通过 Supabase signUp 初始化，激活方式为点击发送至邮箱的确认链接
- 用户名 → 邮箱 的别名映射维护在 `src/views/AuthView.vue` 的 `ACCOUNT_ALIAS`
- 安全建议：初始密码在聊天中传递过，**首次登录验证后请尽快在 Supabase 控制台修改密码**

### 4.3 登录交互（Notion / Claude 式两步登录）
1. 第一步：输入「邮箱或用户名」→ 点击「继续」
2. 第二步：展示账号胶囊，输入密码（自动聚焦）→ 点击「登录」
3. 会话由 supabase-js 持久化，刷新不掉线；过期自动回登录页

### 4.4 新增成员流程
**方式一（推荐，零代码）**：Supabase 控制台 → Authentication → Users → Add user → 填邮箱 + 临时密码 → 勾选 **Auto confirm user** → Create。新成员在登录页直接输**邮箱** + 密码登录。改密/重置密码均在控制台操作（应用内暂不提供自助改密）。
**方式二（需用户名登录时）**：在 `src/views/AuthView.vue` 的 `ACCOUNT_ALIAS` 增加一行 `用户名: '邮箱'`，提交并部署。

## 六、安全设计与待办

### 已实施
- anon key 环境变量化；前端渲染全部使用文本节点防 XSS
- 路由守卫 + 会话持久化

### 待实施（阶段三）
1. **RLS 策略**（Supabase SQL 编辑器执行）：
```sql
alter table public.dw_tables enable row level security;
-- 登录用户可读
create policy "authenticated can select"
  on public.dw_tables for select to authenticated using (true);
-- 仅管理员可写（按邮箱限定）
create policy "admin can write"
  on public.dw_tables for all to authenticated
  using (auth.jwt() ->> 'email' = 'yuanwdii@gmail.com')
  with check (auth.jwt() ->> 'email' = 'yuanwdii@gmail.com');
```
2. **关闭自助注册**：Supabase 控制台 → Authentication → Providers → Email → 关闭「Confirm email」旁的注册开关（或 Auth → Settings → Disable new user signups）
3. **SMTP 正式配置**：默认 SMTP 有每小时发信限额，建议接入 Resend 等发信服务（Authentication → Emails → SMTP Settings）

## 附录：全站视觉规范（强制）

适用于所有现有与未来页面（登录页、首页及后续功能页），新页面不得自行定义背景色系。

| 项 | 规范 |
|----|------|
| 页面背景 | 统一亮白 `#FFFFFF`（禁用 #FAF9F5 等暖暗白） |
| 卡片底色 | 与页面背景同色 `#FFFFFF`，用边框区分 |
| 边框 | `1px solid #E9E9E7`（卡片/胶囊/导航分隔）；输入框 `#E4E4E2` |
| 微对比色 | 表头 / 行悬停 / 按钮悬停 用中性 `#FAFAFA` / `#F5F5F4` |
| 文字 | 主 `#141413`；次 `#5E5D59`；占位符 `#9B9A94` |
| 聚焦高亮 | 蓝色 `#409EFF` 边框，不加外圈光晕 |
| 主按钮 | 近黑 `#141413`、白字、圆角 10px，与输入框等宽 |
| 标题字体 | Anthropic Serif，回退 Georgia / Songti SC |
| 正文字体 | Anthropic Sans，回退 Helvetica Neue / PingFang SC |
| 语义色 | 层级徽章暖色分层（ODS 灰褐 / DWD 灰绿 / DWS 灰蓝 / DIM 灰紫 / ADS 陶土）；品牌点缀陶土橙 `#C15F3C` 仅少量强调 |
